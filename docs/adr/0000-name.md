# ADR-0000: Package name

## Situation

The repository began as an empty `merminal` gem. The design names its public API `MermaidTerm`.

## Decision

Use gem `mermaid_term`, module `MermaidTerm`, and executable `mmterm`.

## Reason

The names match the documented API and communicate the terminal Mermaid purpose. The RubyGems API returned 404 for `mermaid_term` during implementation.

## Result

The previous generated gem name is removed. Publication still requires an owner and a release decision.
